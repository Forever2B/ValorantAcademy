## Duelistas

Phoenix

```
<li>usar suas bangs para cegar os inimigos e se curar com suas habilidades</li>
```

```
<li>Utilize sua ultimate para iniciar uma entrada sem colocar sua vida principal em risco.</li>
```

Jett

```
<li>dominar espaços rapidamente com seu desh e seu hapidreft (pulo)</li>
```

```
<li>Combine o dash com as fumaças para entrar no bombsite enquanto seus companheiros avançam.</li>
```

Raze

```
<li>limpar espaços com suas granadas e dominar espaços com suas cargas explosivas</li>
```

```
<li>Combine as cargas explosivas com os saltos para alcançar posições inesperadas e surpreender os inimigos.</li>
```

Reyna

```
<li>uma duelista capas de usar Bangs e ao eliminar um inimigo pode se curar ou ficar invisível</li>
```

```
<li>Use a invisibilidade para reposicionar depois de uma eliminação e evitar ser trocada rapidamente.</li>
```

Yoru

```
<li>Pode usar das suas bangs para limpar espaços e fazer o primeiro duelo ou jogar um clone para enganar o inimigo ou dar um teleporte em lugares estratégicos</li>
```

```
<li>Combine o clone com a flash para forçar os inimigos a reagirem e abrir espaço para sua equipe.</li>
```

Neon

```
<li>Aproveite a velocidade de corrida para rotacionar de um bombsite para o outro ou mesmo para tirar a mira dos oponentes obtendo um slide para dificultar mais ainda</li>
```

```
<li>Alterne entre correr e caminhar para não entregar sua posição com o som dos passos.</li>
```

Iso

```
<li>esse agente não é um agente de domínio rápido como jett e neon ele tem um escudo como habilidade primária que não deixa ele tomar o primeiro tiro q ajuda nas trocadores</li>
```

```
<li>Procure duelos individuais, pois suas habilidades são especialmente úteis para enfrentar adversários isolados.</li>
```

Waylay

```
<li>Com o seu duplo desh ela consegue fazer um entre com muita velocidade e tendo um teleporte para voltar rapidamente se algo der errado</li>
```

```
<li>Combine sua velocidade com o avanço dos companheiros para criar pressão em diferentes posições.</li>
```

Hush

```
<li>Ela tem uma função que somente ela tem como duelista que é pode controlar suas habilidades no ar podendo puxar o inimigo um pouco para o lado tirando ele do do lugar q está e puxando as armas ou até a bomba para ela</li>
```

```
<li>Utilize suas habilidades durante os confrontos, quando o adversário estiver concentrado na mira.</li>
```

## Iniciadores

Sova

```
<li>o agente usa o spot e o seu drone para revelar onde estão os inimigos</li>
```

```
<li>Aprenda alinhamentos de flechas para revelar posições importantes sem precisar se expor.</li>
```

Breach

```
<li>Jogue sempre olhando o minimap  suas habilidades passam por paredes ajudando os duelistas mesmo sem precisar se arriscar</li>
```

```
<li>Evite utilizar suas habilidades sem avisar a equipe, pois elas também podem atrapalhar seus próprios aliados.</li>
```

Skye

```
<li>Sua habilidade de cura curam todos os aliados na área ao mesmo tempo e pode usar seu cachorro para coletar informações</li>
```

```
<li>Avise seus companheiros antes de utilizar as flashes para evitar que eles sejam cegados.</li>
```

KAY/O

```
<li>Sua faca de supressão cancela as ultimates e habilidades durante 5 segundos, contendo duas Bangs também.</li>
```

```
<li>Utilize a faca antes de entrar no bombsite para descobrir quantos inimigos foram atingidos e impedir suas habilidades temporariamente.</li>
```

Fade

```
<li>O Espreitador  segue as trilhas limpando espaço e coletando informações e tendo um spot q usado perfeitamente mostra onde estão os oponentes</li>
```

```
<li>Utilize sua ultimate antes de uma entrada importante para revelar e atrapalhar vários adversários.</li>
```

Gekko

```
<li>Você pode recuperar as suas habilidades mesmo depois de usar mas tem somente alguns segundos até sumirem de vez</li>
```

```
<li>Tente recuperar suas criaturas sempre que possível para reutilizá-las durante a rodada.</li>
```

Tejo

```
<li>esse agente tem a função de causar dano com seus foguetes tirando o inimigo da posição usado muito em posplant e contém um drone terrestre q revela onde estão os inimigos</li>
```

```
<li>Combine os foguetes com as habilidades de reconhecimento da equipe para atingir adversários escondidos.</li>
```

## Sentinelas

Chamber

```
<li>Deixe seu teletransporte posicionado antes de limpar um ângulo perigoso</li>
```

```
<li>Depois de conseguir uma eliminação, utilize o teletransporte para escapar antes que os inimigos consigam trocar sua kill.</li>
```

Cypher

```
<li>Nunca repita os mesmos setups de fios e câmeras em rodadas seguidas</li>
```

```
<li>Combine os fios com suas habilidades de dano para punir adversários que tentarem atravessar suas armadilhas.</li>
```

Deadlock

```
<li>Use a barreira de malha para bloquear a passagem ou impedir um avanço rápido com paredes e lentidão</li>
```

```
<li>Guarde suas habilidades para momentos de avanço inimigo, dificultando a execução do ataque adversário.</li>
```

Killjoy

```
<li>Use sua Torreta para coletar informação, não para dar dano, coloque-a em ângulos longos e diferente para avisar por onde o inimigo está vindo</li>
```

```
<li>Aproveite sua ultimate para retomar o bombsite ou impedir que os inimigos consigam realizar o plant.</li>
```

Sage

```
<li>Não guarde a sua parede apenas para o início da rodada, Use no meio do round para travar um avanço inimigo rápido ou garantir um plant/defuse seguro.</li>
```

```
<li>Utilize sua lentidão em passagens estreitas para atrasar o avanço de vários inimigos.</li>
```

Vyse

```
<li>Posicione sua armadilha de isolamento logo atrás da entrada do bombsite. Quando o inimigo passar basta ativar as habilidades e conseguir uma kill fácil</li>
```

```
<li>Combine sua parede com a armadilha para separar um inimigo do restante da equipe e conseguir vantagem numérica.</li>
```

## Controladores

Astra

```
<li>Comunique-se muito. Como você joga no "modo astral", você precisa que seu time avise o momento exato de ativar os puxões e tonturas.</li>
```

```
<li>Guarde algumas estrelas para ajudar na retomada do bombsite ou impedir o avanço adversário.</li>
```

Brimstone

```
<li>Suas fumaças caem exatamente ao mesmo tempo e bloqueiam a visão totalmente. Use as três de uma vez para isolar completamente um bombsite no ataque e a sua molotov para limpar espaços ou para o posplant</li>
```

```
<li>Utilize seu sinalizador para aumentar a velocidade de disparo dos aliados durante uma entrada ou retake.</li>
```

Clove

```
<li>Você pode curar e usar fumaças mesmo depois de morrer. Continue prestando atenção no mapa e ajudando seu time até o fim da rodada podendo usar mesmo depois de morta</li>
```

```
<li>Não tenha medo de participar dos confrontos, mas procure garantir que suas fumaças estejam bem posicionadas antes de morrer.</li>
```

Harbor

```
<li>Use sua cascata para avançar junto com ela, ela serve como um escudo móvel para cruzar áreas abertas com segurança</li>
```

```
<li>Coordene suas paredes com os duelistas para criar entradas mais seguras e evitar confrontos em várias direções.</li>
```

Omen

```
<li>Suas fumaças se regeneram ao longo da rodada. Use-as logo no início para gastar o tempo do inimigo e guarde as próximas para o final do round</li>
```

```
<li>Utilize o teletransporte para mudar de posição durante os confrontos e criar dúvidas na cabeça dos adversários.</li>
```

Viper

```
<li>Decore posicionamentos para jogar suas fumaças e venenos de longe, Ela é mortal para impedir que o inimigo desative a Spike</li>
```

```
<li>Controle seu combustível com atenção para não ficar sem habilidades nos momentos mais importantes da rodada.</li>
```
